# Simple Interest Calculator

A simple command-line Python application designed to calculate simple interest and total amount based on principal, rate, and time.

## Formula
Simple Interest = (Principal * Rate * Time) / 100

## Features
- Calculates simple interest accurately.
- Computes the total payable amount (Principal + Interest).
- Includes basic error handling for non-numeric inputs.

## Requirements
- Python 3.x installed on your system.

## How to Run
1. Clone the repository or download `calculator.py`.
2. Open your terminal or command prompt.
3. Run the script using the following command:
   ```bash
   python calculator.py
